# Labels for Catering

Streamlit app for catering labels. Separate from MO and Recipes.

## Local

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Streamlit Cloud

1. Open [share.streamlit.io](https://share.streamlit.io) and choose **Create app**.
2. Repository: `karol2025-wizard/labels-for-catering`
3. Branch: `main`
4. Main file path: `streamlit_app.py`
5. Deploy.

Community Cloud allows one private app per workspace. This repository is public so it can be deployed alongside MO and Recipes.
