# Labels for Catering

Streamlit app for catering labels. Separate from MO and Recipes.

## Local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud

1. Open [share.streamlit.io](https://share.streamlit.io) and choose **Create app**.
2. Repository: `karol2025-wizard/labels-for-catering`
3. Branch: `main`
4. Main file path: `app.py`
5. Deploy.

The app is private on GitHub. Streamlit Cloud needs access to that repository the first time you connect it.
